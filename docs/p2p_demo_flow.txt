1. KHỞI TẠO HỆ THỐNG
-------------------

a) Cấu trúc thư mục:
```
supply-chain-blockchain/
├── node-data/
│   ├── node1/                 # Node của Samsung
│   │   ├── blockchain.json    # Dữ liệu chuỗi khối
│   │   ├── users.json        # Thông tin người dùng
│   │   └── state.json        # Trạng thái node
│   ├── node2/                 # Node của Tech Distributor
│   └── node3/                 # Node của FPT Retail
├── backend/
│   └── server.js             # Server code cho mỗi node
└── frontend/
    └── dashboard.html        # Giao diện người dùng
```

b) Khởi động các node:
```powershell
# Khởi động node 1 (Samsung)
npm run start-node -- --port=5001 --dataFile=node-data/node1/blockchain.json

# Khởi động node 2 (Tech Distributor)
npm run start-node -- --port=5002 --dataFile=node-data/node2/blockchain.json --peers=http://localhost:5001

# Khởi động node 3 (FPT Retail)
npm run start-node -- --port=5003 --dataFile=node-data/node3/blockchain.json --peers=http://localhost:5001,http://localhost:5002
```

5. ĐỒNG BỘ DỮ LIỆU GIỮA CÁC NODE
-------------------------------

5.1. KHI CÓ TRANSACTION MỚI
```javascript
// 1. Node tạo block mới
const newBlock = await blockchain.createBlock(transaction);

// 2. Lưu vào blockchain local
await blockchain.addBlock(newBlock);

// 3. Broadcast tới các node khác
await peers.broadcastBlock(newBlock);

// 4. Các node khác verify và thêm block
peers.on('newBlock', async (block) => {
    if (await blockchain.isValidBlock(block)) {
        await blockchain.addBlock(block);
    }
});
```

5.2. KHI NODE MỚI THAM GIA
```javascript
// 1. Node mới kết nối với peers
await peerManager.connect(['http://localhost:5001']);

// 2. Yêu cầu blockchain hiện tại
const chain = await peers.requestCurrentChain();

// 3. Verify và đồng bộ
if (await blockchain.isValidChain(chain)) {
    await blockchain.replaceChain(chain);
}
```

6. XỬ LÝ LỖI VÀ RECOVERY
-----------------------

6.1. NODE FAILURE
```javascript
// 1. Detect node failure
peerManager.on('nodeDown', async (nodeUrl) => {
    // Remove from active peers
    await peerManager.removePeer(nodeUrl);
    // Notify admin
    await notifyAdmin(`Node ${nodeUrl} is down`);
});

// 2. Node recovery
async function recoverNode() {
    // Get latest chain from peers
    const chains = await peerManager.requestChainsFromPeers();
    // Select longest valid chain
    const validChain = await blockchain.selectValidChain(chains);
    // Replace local chain
    await blockchain.replaceChain(validChain);
}
```

6.2. CONFLICT RESOLUTION
```javascript
// Khi phát hiện conflict
async function resolveConflict() {
    // Get all chains from peers
    const chains = await peerManager.getAllChains();
    
    // Validate each chain
    const validChains = await Promise.all(
        chains.map(chain => blockchain.validateChain(chain))
    );
    
    // Select longest valid chain
    const longestChain = selectLongestChain(validChains);
    
    // Replace local chain if needed
    if (longestChain.length > blockchain.getCurrentChain().length) {
        await blockchain.replaceChain(longestChain);
    }
}
```

```javascript
async function checkPermission(req, res, next) {
    const token = req.headers.authorization;
    const user = await verifyToken(token);
    
    if (!user) {
        return res.status(401).json({
            error: 'Unauthorized'
        });
    }
    
    if (!hasPermission(user.role, req.path)) {
        return res.status(403).json({
            error: 'Permission denied'
        });
    }
    
    next();
}
```

9. BACKUP VÀ RESTORE
------------------

9.1. AUTOMATED BACKUP
```javascript
// Backup định kỳ
schedule.every('1d').do(async () => {
    const timestamp = new Date().toISOString();
    const backupPath = `backups/${config.nodeId}_${timestamp}`;
    
    // Backup blockchain
    await fs.copy(
        `node-data/${config.nodeId}/blockchain.json`,
        `${backupPath}/blockchain.json`
    );
    
    // Backup state
    await fs.copy(
        `node-data/${config.nodeId}/state.json`,
        `${backupPath}/state.json`
    );
});
```

9.2. RESTORE PROCEDURE
```javascript
async function restoreFromBackup(backupId) {
    // Stop node
    await stopNode();
    
    // Restore files
    await fs.copy(
        `backups/${backupId}/blockchain.json`,
        `node-data/${config.nodeId}/blockchain.json`
    );
    
    // Verify restored data
    if (!await blockchain.verifyChain()) {
        throw new Error('Restored chain is invalid');
    }
    
    // Restart node
    await startNode();
    
    // Sync with peers
    await syncWithPeers();
}
```
